## 결론

1. **최근 구간(2026-06-05 이후 17주)에는 사후 확정된 국면 전환이 없었다.** 당시 모델은 매주 "강세"로 진단했고(18/18주 일치), 4주 전환확률을 9~11%, 13주 전환확률을 21~25%로 냈으며 실제 전환은 0건이다. 표본이 h=1·4·13주에서 각 17·14·5점이고 사건이 0건이라 이 구간만으로는 통계적 결론을 내릴 수 없다. "현재 국면 유지" 기준선은 이 구간에서 오차 0이라 skill을 정의할 수 없다.
2. **걸어서 검증(2013-01-04 ~ 2026-10-02, 매주 재적합 ②)에서 전환확률은 "현재 국면 유지"(B1)보다 h=4·13주에서 분명히 낫다.** skill = 1 − Brier/Brier_B1 이 h=4 0.13(90% 구간 0.07~0.17), h=13 0.30(0.20~0.39). **"장기 평균 전이빈도"(B2) 대비는 작다.** h=1 0.01(0.00~0.03), h=4 0.04(0.01~0.07), h=13 0.09(0.02~0.16). 즉 모델의 정보는 "국면은 지속된다"는 사실에서 대부분 나오고, 장기 빈도 이상의 추가 정보는 13주 기준 약 9% 오차 감소에 그친다.
3. **캘리브레이션은 h=4·13에서 대각선 근처다.** h=13 ②: 예측 0.1~0.2 구간(269건) 실제 15.2%, 0.2~0.3(284건) 20.1%, 0.3~0.4(57건) 33.3%, 0.4~0.5(72건) 54.2%, 0.5~0.6(23건) 52.2%. h=4: 0~0.1(462건) 6.7%, 0.1~0.2(199건) 15.6%, 0.2~0.3(53건) 22.6%.
4. **국면 진단(필터 p_t 대 사후 라벨)은 718주 중 91.5% 일치(②).** 전환 20회의 탐지 지연은 중앙값 2주, 최대 7주(2015-11-20 약세 진입). 거짓경보 15회(29주).
5. **당시 모델 고정(①)이 ②보다 좋게 나오는 것은 ①의 파라미터가 2026-06까지의 전체 표본으로 적합된 사후 파라미터이기 때문이다.** 실시간 성능의 기준은 ②다.
6. **당시 발표값 2026-06-05 P(약세) 2.92%는 수요일(06-03)까지만 수집된 부분주 값이다.** 완결주(주간수익률 −2.62%) 기준으로 당시 파라미터를 고정해 다시 필터하면 12.98%(② 12.73%)다. 이후 17주 동안 필터 P(약세)는 1.8~10.6%에 머물렀고 2026-10-02 값은 1.8%다.

## 손 검산 (코드와 독립, 2026-10-02 기준, ① 당시 전이행렬)

p_t = 0.01825(2026-10-02 필터 P(약세)). P0 = [[강→강 0.97295, 강→약 0.02705], [약→강 0.07240, 약→약 0.92760]].
- 1주 후 약세확률 = (1−0.01825)×0.02705 + 0.01825×0.92760 = 0.02656 + 0.01693 = **0.04348** (스크립트 0.04348).
- 1주 후 전환확률 = 0.98175×(1−0.97295) + 0.01825×(1−0.92760) = 0.02656 + 0.00132 = **0.02788** (스크립트 0.02788).
- P0² = [[0.94859, 0.05141], [0.13760, 0.86240]], P0⁴ = P0²·P0² = [[0.90689, 0.09311], [0.24919, 0.75081]] (예: 0.94859² + 0.05141×0.13760 = 0.89982 + 0.00707 = 0.90689).
- 4주 후 약세확률 = 0.98175×0.09311 + 0.01825×0.75081 = 0.09141 + 0.01370 = **0.10511** (스크립트 0.10511). 4주 후 전환확률 = 0.98175×0.09311 + 0.01825×0.24919 = 0.09141 + 0.00455 = **0.09596** (스크립트 0.09595).
- 1주 후 약세확률 수동식은 statsmodels의 predicted_marginal_probabilities 와 2.2e-16 이내로 일치. 엑셀 `전이행렬` 시트에 같은 계산이 수식으로 들어 있다.

## 한계

- **최근 구간은 검증이 아니라 관찰이다.** 전환 0건, 최대 17점. 결론 1~3은 2013~2026 걸어서 결과에 근거한다.
- **걸어서 재적합은 2013-01부터만 가능했다.** 원본 적합 절차(시드 42, 무작위 시작값 20회, 기본 반복 한도)는 2005-01~2011-07의 모든 주간 표본에서 예외 또는 수렴 실패(파라미터 퇴화: 강→약 ≈ 1.0, 분산비 ~1e30)였고, 2011-08-05 1회 수렴 후 2012년은 전부 예외였다. 2011-08~2012-12는 단일 적합 파라미터를 75주 이월한 참고 구간으로 분리했다(`②가용` 구간, 엑셀 `지표` 시트). 2008년 위기는 검증 구간에 없다.
- **사후 라벨이 같은 모델의 평활 확률이다.** 외부 기준(예: 20% 하락)이 아니라 모델 기준 라벨이며, 마지막 8주(2026-08-14~)는 데이터가 쌓이면 바뀔 수 있는 잠정 라벨이다. θ0 평활 라벨과는 1,348주 중 1주만 다르다.
- **전이행렬이 시간 불변이다.** 전환확률의 시점 변동은 전부 p_t에서 온다. 모델이 B2를 크게 못 이기는 구조적 이유다.
- **표본이 겹친다.** 연속 주의 h주 목표가 서로 상관되어 블록 부트스트랩 구간만 제시했다. 사건 수(h=1 20건)도 작다.
- **원본 코드 문제(수정 안 함).** ① `np.random.seed(42)`는 statsmodels 0.15 이상에서는 시작값 탐색 난수를 고정하지 못한다(`fit(rng=None)`이 OS 엔트로피로 새 Generator 생성). 같은 데이터·같은 시드로도 실행마다 다른 국소해가 나올 수 있어 재현성은 0.14.6에서만 성립한다. ② 수렴 실패는 화면 경고만 하고 값은 그대로 쓴다. ③ 화면의 "현재" P(약세)는 수집 요일에 따라 부분주 값이 된다.
- 데이터: 확장 구간의 XLI(배당 조정)·금 선물(계약 교체)·NFCI(소급 수정)에 이어붙임 단절이 있으나 MS-AR 입력(S&P500 수익률)과 무관. 월별 거시 컬럼은 발표일 기준이 아니나 역시 입력 아님.
